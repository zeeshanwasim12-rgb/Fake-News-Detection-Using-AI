# Presentation plan

Audience: internship evaluator and project reviewer.

Objective: explain the problem, complete from-scratch pipeline, added dataset
analysis, evaluation outputs, and limitations of a text-only fake-news classifier.

Narrative arc: problem, data, pipeline, models, evaluation, findings and
limitations, then next steps.

Slides: title; problem and objectives; data and exploratory analysis; text
preprocessing and features; four-model comparison; evaluation outputs; results,
limitations, and discussion; conclusion and reproducibility.

Visual system: deep navy background, teal and coral accents, Poppins/Lato
typography, abstract newspaper/data textures, and editable foreground content.

Source plan: local project code, the supplied assignment brief, and pipeline
outputs. No fixed metric values are reported because they depend on the final
real dataset chosen by the student.

Editability plan: all titles, explanatory copy, model labels, charts, and
workflow steps are native PowerPoint objects. Decorative images are text-free.
