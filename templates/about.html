About & Methodology

How this project works, and what its results do and don't mean.

Pipeline (built from scratch)

StageTechnique
CleaningRegex punctuation/URL/digit removal, lowercasing
TokenizingWhitespace tokenizer + custom stopword list + rule-based stemmer
FeaturesTF-IDF (hand-coded formula), optional bigrams, L2-normalized
ModelsKNN, Logistic Regression (gradient descent), Random Forest (bagged Gini trees), 1-hidden-layer Neural Net (manual backprop)
EvaluationAccuracy / precision / recall / F1 / confusion matrix, computed manually

No sklearn, nltk, or gensim is used anywhere — every algorithm is implemented with NumPy directly in src/.

⚠️ Honest limitations

  • This tool's accuracy is only as good as its training data. If data/news.csv is still the bundled synthetic demo set, the model has learned artificial writing patterns, not real-world misinformation signals.
  • No single classical ML model can reliably flag "any" fake news — real misinformation detection at scale uses much larger, human-labeled datasets and often combines text models with source credibility, fact-checking databases, and human review.
  • TF-IDF + these four models can't verify facts — they detect writing style patterns (sensational language, formatting, etc.), which is a real but limited signal.
  • Treat every prediction here as a starting point for scrutiny, not a verdict.

Get better results

Replace data/news.csv with the real Kaggle "Fake and Real News Dataset" or the UCI Fake News Dataset (same text,label column format — see the project README), then restart app.py. The dashboard and checker will automatically retrain on the new data.
